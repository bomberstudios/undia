Philosophy

One day, one page, one pen.

Most notebooks give you everything: infinite pages, layers, undo, a hundred brushes. That makes it easy to start and hard to commit.

  • No erasera page only grows
  • No undoa mark is a decision
  • No settingsa 0.2 mm pen, always
  • No new pagetomorrow brings one

undia takes the other road. Each day gets exactly one page, and it opens blank. You can add to it all day, but you can never take anything back.

That small constraint changes how you write. You stop polishing and start noticing. A crossed-out thought stays crossed out, next to the one that replaced it. A bad doodle is still part of the day.

At midnight the page closes and a clean one begins. Yesterday is still there to read, but it’s finished. Today’s page is the only one you can write on.

How it works

Four rules, no manual.

1

One page per day

It opens on a blank page with a fixed pen. Today’s page is the only one you can write on.

2

Renews at midnight

When the date changes, a new blank page starts. If you’re looking at the day that just ended, undia moves you to the new one.

3

The past is read-only

Go back to any earlier day and read it. You can scribble on it, but that ink is gray and dotted: it fades in six seconds and is never saved.

4

Empty days give you a koan

Nothing drawn that day? You get a short koan instead of a blank page, and the same day always shows the same one.

Using it

The pen draws. Fingers do everything else.

Do this To get this
Draw with the pen A 0.2 mm black line.
Tap with one finger Switch between pen and highlighter. The mark at the top right shows which is on: a smallfor the pen, a largerfor the highlighter.
Swipe left or right Next or previous day, never past today.
Double-tap Back to today.
Hold a finger down Open the menu: calendar, copy, save as PDF, share, about.

The highlighter is a 4 mm yellow stroke that keeps your ink readable underneath. It switches back to the pen by itself 0.8 s after a stroke, so you can highlight several things in a row. On the black-and-white panel it shows as light gray.

Under the hood

Plain files, sized for the real panel.

Plain text, open format

One SVG file per day, named yyyy-MM-dd.svg. They open in any browser or vector editor.

Easy to share

Copy a page as a PNG, save it as a vector PDF to Downloads, or share it with Android's native share sheet.

True to size

The pen is 0.2 mm and the highlighter 4 mm on any panel, from the pixel density the device reports.
